# WinNook

WinNook is a native Windows desktop productivity utility inspired by the interaction model of Apple's Dynamic Island, but designed specifically for Windows.

## Features
- **Dynamic Notch**: A customizable notch that sits seamlessly on your screen. It smoothly transitions between Idle, Hover, and Expanded states.
- **Control Center**: A beautiful, modern Control Center built with WPF and `Wpf.Ui` that allows you to configure every detail of the notch.
- **Deep Customization**: Adjust colors, corner rounding, fillet radii, shadows, animations, and dimensions for all notch states (Idle, Hover, Expanded) in real-time.
- **Shelf**: Drag and drop your favorite files, folders, and shortcuts into the Shelf for immediate access anywhere.
- **Dive In**: Automatically scans your Start Menu and Registry to discover installed apps (including Chrome, Spotify, etc.) and allows you to add them to your Quick Access.
- **Danger Zone**: One-click kill switch and uninstaller.

## Built With
- C# .NET 8.0
- Windows Presentation Foundation (WPF)
- Wpf.Ui (Modern Fluent UI controls)
